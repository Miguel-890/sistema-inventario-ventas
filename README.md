# sistema-inventario-ventas

Fase 1: El Núcleo (Producto Mínimo Viable - MVP)

- Ver lista de productos.
- Agregar productos (Nombre, Precio, Cantidad).
- Crear una venta.
- Disminuir el stock automáticamente.

Fase 2: Expansión

- Sistema de login y credenciales.
- Dashboard de estadísticas (más y menos vendidos).
- Descuentos por tiempo limitado.

Objetivos a largo Plazo
    * El usuario puede ver una lista de todos los productos.
    * El usuario puede agregar un producto (Nombre, Precio, Cantidad Inicial).
    * El usuario puede crear una Venta sumando varios productos.
    * El usuario puede tener sus credenciales con contraseña para que pueda tener su cuenta.
    * El usuario puede ver las estadísticas de los productos del inventario y los productos que mas se venden y menos se venden.
    * El usuario puede poner descuentos por tiempo limitado.
    * Al confirmar la Venta, el stock de los productos vendidos disminuye automáticamente.
